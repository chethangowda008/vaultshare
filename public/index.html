🛡 Security Architecture
🔑
AES-256 Encryption
Uses AES with 256-bit keys in GCM, CBC, or CTR mode. GCM provides authenticated encryption to detect tampering.
🧂
PBKDF2 Key Derivation
Password is never used directly. PBKDF2-SHA256 with up to 1M iterations and a random 256-bit salt.
🎲
Random IV Per File
A fresh cryptographically random IV is generated for every encryption operation.
🔏
Integrity Verification
SHA-256 hash of original plaintext embedded and verified on decryption.
🌐
Zero Server Contact
All operations use the browser's native Web Crypto API. Nothing leaves your device unencrypted.
📦
Self-Describing Package
Output carries a structured header: version, algorithm, salt, IV, original filename, and hash.
VaultShare — All crypto runs in your browser. Open source. Zero telemetry.
